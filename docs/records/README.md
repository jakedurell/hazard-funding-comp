# Public records requests

Drop request letters and any responses here as PDFs. The landing page links to this
directory, so anything added becomes citable evidence alongside the data.

Suggested naming so files sort chronologically and read clearly in a list:

    YYYY-MM-DD-<recipient>-<subject>.pdf

    2026-02-14-ntb-hmgp-application-records.pdf
    2026-03-02-ntb-response-powerpoint-only.pdf
    2026-03-18-ncem-dr4827-loi-submissions.pdf

Two things to check before adding a file:

- **Redact first.** Anything here is published to data.reefadvocate.com. Remove personal
  contact details, account numbers, and anything not already public record.
- **Responses matter as much as requests.** A non-response, a partial response, or a
  response that supplies only a slide deck is itself the finding. Keep the request and
  whatever came back as separate files so the pairing is visible.

After adding files, list them in the "Records requests" section of `docs/index.html`.
